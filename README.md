# Afecções Clínicas

Resumo interativo para estudar afecções clínicas (Enfermagem, 4º período).

- **Sete sistemas:** neurológico, endócrino, gastrointestinal, urinário, hematológico, cardiovascular e respiratório
- **Mapa do corpo clicável** para escolher o sistema
- **Cartões de doença** com o que é, sinais, diagnóstico, tratamento e cuidados de enfermagem
- **Busca** em todos os sistemas
- **Questionário** de múltipla escolha com correção e comentário para cada erro
- **Treino** com flashcards

Colinha completa para imprimir: [`colinha/Colinha-Afeccoes-Clinicas.pdf`](colinha/Colinha-Afeccoes-Clinicas.pdf)

## Como abrir

Abra o `index.html` no navegador. Para publicar online, ative o GitHub Pages em
**Settings → Pages → Branch: main / (root)**.

Conteúdo e imagens baseados nas aulas do Prof. Felipe Ferraz Fideles (Univel) e no Brunner & Suddarth, 14ª edição.
